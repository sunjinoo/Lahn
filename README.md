# 🎵 Lahn (لحن) - All-in-One Music Player

**Lahn** is a comprehensive Progressive Web App (PWA) that works offline. It is carefully designed to be your ultimate music player, Holy Quran reader, and podcast player in one place, featuring a modern and extremely fast interface.

## ✨ Features

- **Library Management:** Play local audio files (MP3, FLAC, WAV, M4A).
- **Holy Quran:** Listen to the Quran with famous reciters, with the ability to download Surahs for offline listening.
- **Live Radio:** Listen to live radio stations from around the world.
- **Podcasts & Music:** Search for podcast episodes (via iTunes) and independent music (via Audius).
- **Pro Audio Processing:**
  - Audio Effects (Nightcore / Slowed + Reverb).
  - 8D Audio.
  - Multi-band Equalizer.
  - Volume Normalization.
- **Dynamic UI:** Dynamic Blurred Background based on the album art.
- **Multi-language Support:** Interface supports 8 languages (Arabic, English, French, etc.).
- **Offline Mode:** Powered by Service Worker and IndexedDB.
- **Full Customization:** 15+ Themes (Skins) and a Classic Mode.

## 🛠️ Tech Stack

- **HTML5 / CSS3 / Vanilla JavaScript**
- **Web Audio API** (for audio effects and equalizer).
- **IndexedDB & LocalStorage** (for caching songs and settings).
- **Service Worker** (for offline capability).
- **APIs:** Mp3Quran, Radio Browser, Audius, iTunes, Deezer, LRCLIB.

## 🚀 How to Run Locally

Since the app relies on `fetch` to get data from the internet (Quran, Radio, etc.), it cannot be opened directly via `file://`. You must run it through a local server:

1. Clone or download the project.
2. Open the folder in **Visual Studio Code**.
3. Install the **Live Server** extension.
4. Right-click on `index.html` and select **Open with Live Server**.

# 🎵 لحن (Lahn) - مشغل الموسيقى الشامل

**لحن** هو تطبيق ويب تقدمي (PWA) متكامل، بيشتغل أوفلاين، ومصمم بعناية عشان يكون مشغل موسيقى وقرآن كريم وقارئ بودكاست في مكان واحد، بواجهة عصرية وسريعة جداً.

## ✨ المميزات

- **إدارة المكتبة:** تشغيل ملفات الصوت المحلية (MP3, FLAC, WAV, M4A).
- **القرآن الكريم:** الاستماع للقرآن الكريم بصوت أشهر الشيوخ، مع إمكانية تحميل السور للاستماع بدون إنترنت.
- **بث مباشر:** الاستماع لإذاعات الراديو المباشرة من جميع أنحاء العالم.
- **بودكاست وأغاني:** البحث عن حلقات بودكاست (عبر iTunes) وأغاني مستقلة (عبر Audius).
- **معالجة صوتية احترافية:** 
  - مؤثرات صوتية (Nightcore / Slowed + Reverb).
  - صوت محيطي (8D Audio).
  - معادل صوتي (Equalizer) متعدد الشرائط.
  - توحيد مستوى الصوت (Normalization).
- **واجهة ديناميكية:** خلفية متغيرة (Blurred Background) حسب صورة الغلاف.
- **دعم متعدد اللغات:** واجهة تدعم 8 لغات (العربية، الإنجليزية، الفرنسية، إلخ).
- **يعمل بدون إنترنت (Offline):** بفضل الـ Service Worker والتخزين المحلي (IndexedDB).
- **تخصيص كامل:** أكثر من 15 ثيم (Skin)، ووضع كلاسيكي.

## 🛠️ التقنيات المستخدمة

- **HTML5 / CSS3 / Vanilla JavaScript**
- **Web Audio API** (للمؤثرات الصوتية والمعادل).
- **IndexedDB & LocalStorage** (لتخزين الأغاني والإعدادات).
- **Service Worker** (للعمل أوفلاين).
- **APIs:** Mp3Quran, Radio Browser, Audius, iTunes, Deezer, LRCLIB.

## 🚀 طريقة التشغيل محلياً

بما أن التطبيق يعتمد على `fetch` لجلب البيانات من الإنترنت (القرآن، الراديو، إلخ)، لا يمكن فتح الملف مباشرة بـ `file://`. يجب تشغيله عبر سيرفر محلي:

1. قم بتحميل المشروع أو عمل Clone.
2. افتح المجلد في **Visual Studio Code**.
3. قم بتثبيت إضافة **Live Server**.
4. اضغط كليك يمين على `index.html` واختر **Open with Live Server**.
